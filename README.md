# Погода (React + TypeScript)

![CI](../../actions/workflows/ci.yml/badge.svg)

Приложение с прогнозом погоды на React 19, TypeScript и Vite. Без API-ключей и регистрации.

Демо: https://1elmmmn.github.io/weather-app-react/

<!-- Добавьте сюда скриншот: ![Скриншот](docs/screenshot.png) -->

## Возможности

- Поиск города с подсказками (дебаунс, отмена устаревших запросов, управление с клавиатуры)
- Определение местоположения через Geolocation API
- Текущая погода: температура, ощущаемая температура, ветер, влажность, давление (мм рт. ст.), УФ-индекс, восход и закат
- Почасовой прогноз на 24 часа и прогноз на 7 дней с полоской диапазона температур
- Избранные города (до 8), последний выбранный город запоминается
- Переключение °C / °F (вместе с м/с и миль/ч)
- Светлая и тёмная темы: следуют системной настройке, переключаются вручную
- Фон меняется в зависимости от погоды и времени суток
- Состояния загрузки (скелетон), ошибок с кнопкой «Повторить» и «ничего не найдено»

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # тесты (Vitest + Testing Library)
npm run lint       # ESLint
npm run build      # проверка типов и сборка в dist/index.html
```

`npm run build` создаёт **один самодостаточный файл** `dist/index.html` (JS и CSS встроены). Его можно открыть двойным кликом, выложить на любой хостинг или на GitHub Pages.

## Стек

React 19 (хуки, без классов), TypeScript в строгом режиме, Vite, Vitest + React Testing Library + user-event, ESLint (включая правила хуков). Данные: [Open-Meteo](https://open-meteo.com/) (прогноз и геокодинг) и [BigDataCloud](https://www.bigdatacloud.com/) (название города по координатам).

## Структура

```
src/
  App.tsx                    состояние приложения и компоновка страницы
  types.ts                   доменные типы
  components/
    Header.tsx               шапка: поиск, геолокация, единицы, тема
    CitySearch.tsx           поле поиска (ARIA combobox)
    Favorites.tsx            избранные города
    CurrentWeather.tsx       главная карточка
    HourlyForecast.tsx       почасовой прогноз
    DailyForecast.tsx        прогноз на 7 дней
    WeatherDetails.tsx       ветер, влажность, давление, УФ…
    Skeleton.tsx, ErrorCard.tsx
  hooks/
    useForecast.ts           загрузка прогноза и отмена запросов
    useCitySearch.ts         поиск с дебаунсом
    useGeolocation.ts        определение местоположения
    useLocalStorage.ts       состояние, которое сохраняется
    useTheme.ts              светлая / тёмная тема
    useDebouncedValue.ts
  lib/
    api.ts                   запросы, ошибки, кэш на 10 минут
    model.ts                 приведение ответа API к модели интерфейса
    format.ts                чистые функции форматирования
    parse.ts                 проверка данных из localStorage
    weatherCodes.ts          коды погоды WMO → подпись, иконка, фон
    storage.ts
  test/                      настройка тестов и тестовые данные
```

## Архитектурные решения

- **Слои разделены.** `lib/` ничего не знает про React и DOM (и тестируется без них), `hooks/` связывают `lib/` с React, `components/` только отображают данные и сообщают о действиях.
- **Нет устаревших ответов.** `useForecast` хранит результат вместе с ключом запроса (место, единицы, номер попытки) и показывает его, только если ключ совпадает с текущим. Каждый новый запрос отменяет предыдущий через `AbortController`, поэтому быстрое переключение городов не покажет данные не того места. Заодно в эффекте не нужен синхронный `setState`.
- **Время города не проходит через `Date`.** Open-Meteo отдаёт локальное время без смещения; разбор через `new Date()` сдвинул бы его в часовой пояс браузера. Время берётся срезом строки.
- **Недоверенные данные.** Всё из `localStorage` проходит через `parse.ts` перед попаданием в состояние. Тексты из API выводятся как обычный текст (React экранирует их), и это проверено тестом.
- **Доступность.** Семантическая разметка, ARIA combobox для поиска, `aria-live` для статусов, видимые фокусы, ссылка «Перейти к прогнозу», поддержка `prefers-reduced-motion`.
- **Тесты на уровне поведения.** `App.test.tsx` проверяет приложение глазами пользователя: поиск, выбор с клавиатуры, избранное, единицы, ошибки с повтором, тема, геолокация, испорченный `localStorage`. Сеть подменяется, поэтому тесты быстрые и стабильные.

## Ограничения и идеи для развития

- Бесплатный API Open-Meteo предназначен для некоммерческого использования; для коммерческого проекта нужен платный тариф.
- Иконки погоды — системные эмодзи, поэтому выглядят по-разному на разных платформах. Можно заменить на SVG-набор.
- Что добавить дальше: PWA и офлайн-режим, e2e-тесты на Playwright, графики температуры, перевод интерфейса, маршрутизация (`/moscow`) для ссылок на конкретный город.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите проект (ветка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт проект и опубликует `dist/` при каждом пуше в `main`.
